# DoMeRa

**DoMeRa** is an independent new research project in development by **Chen Tang**, building on insights from the publicly accessible [DeMoP](https://github.com/DawnLightRise/DeMoP) but separate from DeMoP.

DeMeRa employs more advanced techniques and a mixture-of-experts architecture with adaptive routing, using significantly fewer parameters while potentially achieving better performance on evaluation metrics and demonstrating greater transferability and generalizability.
