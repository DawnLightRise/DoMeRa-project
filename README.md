# DoMeRa

**DoMeRa** is an independent new research project in development by **Chen Tang**, building on insights from [DeMoP](https://github.com/DawnLightRise/DeMoP) but separate from DeMoP.

DoMeRa explores newer modeling techniques and mixture of adaptively routed experts, with substantially fewer trainable parameters.
